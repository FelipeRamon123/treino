# Treino · Bloco A

Guia visual de treino para uso no navegador, com timer, avisos sonoros e vibração quando disponíveis.

## Publicação

O site é estático: basta abrir `index.html` ou publicá-lo em qualquer hospedagem estática.

## Mídias

As animações são carregadas a partir do projeto [Exercises Dataset](https://github.com/hasaneyldrm/exercises-dataset). As imagens e GIFs pertencem à Gym Visual e continuam sujeitos aos termos da fonte. Este repositório não reivindica propriedade sobre essas mídias.
